# BusDrop web frontend

Next.js replay of the Anna Salai morning peak. Pick a scenario, watch buses move on the corridor diagram, and compare with/without-handoff outcomes. The page calls the Python engine through same-origin `/api/*` route handlers, which proxy to FastAPI on port 8000.

## Run it

From the repo root, start the engine first:

```bash
.venv/bin/uvicorn api:app --port 8000
```

Then, in `web/`:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). If the engine runs elsewhere, set `BUSDROP_ENGINE=http://host:8000` for the Next.js server.

## Checks

```bash
npm run lint
npm run build
```

## Notes

- No API keys needed: scripted and baseline runs work offline. The Spark dispatcher option needs `MODEL_API_KEY` in the repo-root `.env`, and falls back to scripted with a notice when Spark is unreachable.
- `AGENTS.md` is auto-generated by `next dev`; `api.py` response shapes mirror `dashboard/app.py`'s recorder (same engine, same numbers).
